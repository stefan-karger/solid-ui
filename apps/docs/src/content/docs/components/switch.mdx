## Disabled

Set `disabled` on `Switch` to prevent interaction. Add `data-disabled` to `Field` to style the rest of the field.

<ComponentPreview name="switch-disabled" />

## Invalid

Set `aria-invalid` on `Switch` and `data-invalid` on `Field` to show the invalid state.

<ComponentPreview name="switch-invalid" />
