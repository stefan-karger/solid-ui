## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "~/components/ui/avatar"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="/avatars/03.png" alt="@alex" />
  <AvatarFallback>AM</AvatarFallback>
</Avatar>
```

## Composition

Use the following composition to build an `Avatar`:

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

Use the following composition to build an `AvatarGroup`:

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

## Badge

Use the `AvatarBadge` component to add a badge to the avatar. The badge is positioned at the bottom right of the avatar.

<ComponentPreview name="avatar-badge" />

Use the `class` prop to customize badge colors and sizing.

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="/avatars/03.png" alt="@alex" />
  <AvatarFallback>AM</AvatarFallback>
  <AvatarBadge class="bg-green-600 dark:bg-green-800" />
</Avatar>
```

## API Reference

### Avatar

Root container for avatar image and fallback content.

| Prop    | Type                        | Default     |
| ------- | --------------------------- | ----------- |
| `size`  | `"default" \| "sm" \| "lg"` | `"default"` |
| `class` | `string`                    | -           |

### AvatarImage

Image element displayed when `src` loads successfully.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `src`   | `string` | -       |
| `alt`   | `string` | -       |
| `class` | `string` | -       |

### AvatarFallback

Fallback element rendered when the image is unavailable.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### AvatarBadge

Badge indicator positioned on top of the avatar.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### AvatarGroup

Container for overlapping avatars.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### AvatarGroupCount

Count indicator for additional avatars in a group.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

See the [UI SDK](https://ui-sdk.dev/docs/solid/components/avatar) documentation for more information.
