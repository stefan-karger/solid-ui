## Usage

```tsx showLineNumbers
import { Calendar } from "~/components/ui/calendar"
```

```tsx showLineNumbers
<Calendar aria-label="Select a date" />
```

Dates use ISO strings, such as `"2026-11-17"`. Set `mode` to `single`, `multiple`, or `range`. `onValueChange` receives the ISO value. Use `months` for multiple grids and `min`, `max`, or `unavailable` for restrictions. The SDK renders focusable table cells, so days do not contain extra buttons.

See the [UI SDK calendar API](https://ui-sdk.dev/docs/solid/components/calendar) for native options and keyboard behavior.

## About

The `Calendar` component styles the grid, day cells, and navigation from [UI SDK Calendar](https://ui-sdk.dev/docs/solid/components/calendar).

## Date Picker

You can use the `<Calendar>` component to build a date picker. See the [Date Picker](/docs/components/date-picker) page for more information.

## Selected Date (With TimeZone)

The Calendar component accepts a `timeZone` prop to ensure dates are displayed and selected in the user's local timezone.

**Note:** If you notice a selected date offset (for example, selecting the 20th highlights the 19th), make sure the `timeZone` prop is set to the user's local timezone.

The SDK uses `timeZone` to determine today. Without it, the SDK reads the browser time zone after hydration.
