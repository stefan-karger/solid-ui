## Usage

```tsx
import {
  Command,
  CommandInput,
  CommandList,
  CommandGroup,
  CommandGroupLabel,
  CommandItem,
  CommandEmpty
} from "~/components/ui/command"

;<Command onAction={(value) => console.log(value)}>
  <CommandInput aria-label="Search commands" placeholder="Search commands..." />
  <CommandList>
    <CommandGroup>
      <CommandGroupLabel>Suggestions</CommandGroupLabel>
      <CommandItem value="calendar">Calendar</CommandItem>
      <CommandItem value="settings">Settings</CommandItem>
    </CommandGroup>
  </CommandList>
  <CommandEmpty>No results found.</CommandEmpty>
</Command>
```

`onAction` receives the command value when a command runs. `onValueChange` reports the highlighted command. Use `query` and `onQueryChange` to control search text; native filtering works with composed items. `CommandDialog` wraps the command palette in a named dialog.

## Composition

Use the following composition to build a `Command`:

```text
Command
├── CommandInput
└── CommandList
    ├── CommandEmpty
    ├── CommandGroup
    │   ├── CommandItem
    │   └── CommandItem
    ├── CommandSeparator
    └── CommandGroup
        ├── CommandItem
        └── CommandItem
```
