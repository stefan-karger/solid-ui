## Installation

The Date Picker is built using a composition of the `<Popover />` and the `<Calendar />` components.

See the installation instructions for [Popover](/docs/components/popover#installation) and [Calendar](/docs/components/calendar#installation).

## Usage

<ComponentSource
  name="date-picker-demo"
  title="components/example-date-picker.tsx"
/>

See the [UI SDK Calendar API](https://ui-sdk.dev/docs/solid/components/calendar) for date values, selection modes, and keyboard behavior.

## Composition

A date picker is built from `Popover` and `Calendar` (there is no `DatePicker` root component):

```text
Popover
├── PopoverTrigger
└── PopoverContent
    └── Calendar
```
