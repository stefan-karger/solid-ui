## Usage

```tsx
import { ResizablePanelGroup } from "~/components/ui/resizable"
```

Use `orientation`, `onLayoutChange`, and `onLayoutCommit` on `ResizablePanelGroup`. Each panel accepts `defaultSize`, `minSize`, `maxSize`, and `collapsible`. Percentages are numbers. Name each handle with `aria-label`. Native SDK controllers replace React panel refs.

See the [UI SDK resizable API](https://ui-sdk.dev/docs/solid/components/resizable) for native options and keyboard behavior.

## Composition

Use the following composition to build a `ResizablePanelGroup`:

```text
ResizablePanelGroup
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```
