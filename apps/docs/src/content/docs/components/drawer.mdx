## Usage

```tsx
import { Drawer } from "~/components/ui/drawer"
```

Use `side`, `snapPoints`, and `defaultSnapPoint` from the SDK. Content renders in place using the browser top layer. The SDK owns positioning and movement. There is no portal or Vaul compatibility layer.

See the [UI SDK drawer API](https://ui-sdk.dev/docs/solid/components/drawer) for native options and keyboard behavior.

## Composition

Use the following composition to build a `Drawer`:

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
```
