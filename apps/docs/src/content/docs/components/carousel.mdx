## About

Carousel is built on the [UI SDK Carousel](https://ui-sdk.dev/docs/solid/components/carousel), which handles paging, swiping, looping, autoplay, and keyboard support.

## Usage

```tsx showLineNumbers
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
  CarouselViewport
} from "~/components/ui/carousel"
```

```tsx showLineNumbers
<Carousel aria-label="Featured slides">
  <CarouselViewport>
    <CarouselContent>
      <CarouselItem>Slide one</CarouselItem>
      <CarouselItem>Slide two</CarouselItem>
    </CarouselContent>
  </CarouselViewport>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

Compose `CarouselViewport` and `CarouselContent` under `Carousel`, then render explicit `CarouselItem` children. Configure it with props on `Carousel`, such as `page`, `onPageChange`, `loop`, `slidesPerPage`, and `controller`. Give vertical viewports an explicit height.

See the [UI SDK carousel API](https://ui-sdk.dev/docs/solid/components/carousel) for native options and keyboard behavior.

## Composition

Use the following composition to build a `Carousel`:

```text
Carousel
├── CarouselViewport
│   └── CarouselContent
│       ├── CarouselItem
│       └── CarouselItem
├── CarouselPrevious
└── CarouselNext
```

## Options

Pass options as props on `Carousel`:

- `loop` continues from the last page to the first.
- `slidesPerPage` sets how many slides one page holds, or `"auto"` to fit as many as the viewport shows.
- `align` sets where a page lines up in the viewport.
- `dragFree`, `skipSnaps`, and `drag` control how swipes and drags move the slides.

See the [UI SDK Carousel API](https://ui-sdk.dev/docs/solid/components/carousel) for every option.

## Controlled

Use `page` and `onPageChange` to read and set the current page. `onPageChange` receives the requested page and change details whose `reason` explains the change. `onPageChangeComplete` runs once the slides come to rest. To page the carousel from elsewhere, pass a `controller` created with `createCarouselController()`.

## Autoplay

Use `defaultPlaying` or `playing` with `interval` to rotate through the pages. Rotation pauses while the carousel is hovered, scrolled out of view, or in a hidden tab, and stops when the user pages. It doesn't start on its own when the user prefers reduced motion.
