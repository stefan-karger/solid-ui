## Usage

```tsx showLineNumbers
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
  CarouselViewport
} from "~/components/ui/carousel"
```

```tsx showLineNumbers
<Carousel aria-label="Featured slides">
  <CarouselViewport>
    <CarouselContent>
      <CarouselItem>Slide one</CarouselItem>
      <CarouselItem>Slide two</CarouselItem>
    </CarouselContent>
  </CarouselViewport>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

Compose `CarouselViewport` and `CarouselContent` under `Carousel`, then render explicit `CarouselItem` children. Native SDK `page`, `onPageChange`, `loop`, `slidesPerPage`, and `controller` replace Embla options and callbacks. Give vertical viewports an explicit height.

See the [UI SDK carousel API](https://ui-sdk.dev/docs/solid/components/carousel) for native options and keyboard behavior.

## Composition

Use the following composition to build a `Carousel`:

```text
Carousel
├── CarouselContent
│   ├── CarouselItem
│   └── CarouselItem
├── CarouselPrevious
└── CarouselNext
```
