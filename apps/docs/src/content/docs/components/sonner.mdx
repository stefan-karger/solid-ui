## About

Sonner is built on [solid-sonner](https://github.com/wobsoriano/solid-sonner) by [wobsoriano](https://github.com/wobsoriano), a Solid port of [Sonner](https://sonner.emilkowal.ski) by [Emil Kowalski](https://github.com/emilkowalski).

## Usage

```tsx showLineNumbers
import { toast } from "solid-sonner"
```

```tsx showLineNumbers
toast("Event has been created.")
```

## Types

Use `toast.success`, `toast.info`, `toast.warning`, or `toast.error` to indicate the outcome. Use `toast.promise` to show a loading toast and update it when the promise settles.

## Position

Toasts appear at the bottom right by default. Set `position` on `Toaster` to change it for every toast, or pass `position` to `toast` for one toast.
