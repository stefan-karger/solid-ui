## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger
} from "~/components/ui/hover-card"
```

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger
    render={(partProps) => (
      <a {...partProps} href="/docs/components/hover-card" />
    )}
    class="underline underline-offset-4"
  >
    Hover
  </HoverCardTrigger>
  <HoverCardContent>
    SolidJS - Simple and performant reactivity for building user interfaces.
  </HoverCardContent>
</HoverCard>
```

## Composition

Use the following composition to build a `HoverCard`:

```text
HoverCard
├── HoverCardTrigger
└── HoverCardContent
```

## Trigger Delays

Use `openDelay` and `closeDelay` on `HoverCard` to control when content opens and closes.

```tsx showLineNumbers
<HoverCard delay={100} closeDelay={200}>
  <HoverCardTrigger
    render={(partProps) => (
      <a {...partProps} href="/docs/components/hover-card" />
    )}
    class="underline underline-offset-4"
  >
    Hover
  </HoverCardTrigger>
  <HoverCardContent side="left" sideOffset={8}>
    Content
  </HoverCardContent>
</HoverCard>
```

## Positioning

Use `side`, `align`, and `sideOffset` on `HoverCardContent` to position the content.

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger
    render={(partProps) => (
      <a {...partProps} href="/docs/components/hover-card" />
    )}
    class="underline underline-offset-4"
  >
    Hover
  </HoverCardTrigger>
  <HoverCardContent>Content</HoverCardContent>
</HoverCard>
```

## API Reference

| Part               | Description                                               |
| ------------------ | --------------------------------------------------------- |
| `HoverCard`        | Root component that manages delays and floating state.    |
| `HoverCardTrigger` | Interactive trigger that opens content on hover or focus. |
| `HoverCardContent` | Floating card content rendered inside a portal.           |

See the [UI SDK](https://ui-sdk.dev/docs/solid/components/hover-card) documentation for more information.
