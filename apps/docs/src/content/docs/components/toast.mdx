## Usage

```tsx showLineNumbers
import { toast } from "~/components/ui/toast"
```

```tsx showLineNumbers
toast("Event has been created.")
```

Use `toast` with the default `Toaster`, or create a separate queue with `createToaster()` and pass it to `<Toaster toaster={queue} />`.

## Types

Use `toast.success`, `toast.info`, `toast.warning`, or `toast.error` to indicate the outcome. Use `toast.promise` to show a loading toast and update it when the promise settles.
