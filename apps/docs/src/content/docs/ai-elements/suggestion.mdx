Suggestion is a prompt you send without typing. Each one is a [Button](/docs/components/button/) with the prompt as its label. Put a row of them above the [Prompt Input](/docs/ai-elements/prompt-input/).

## Usage

```tsx showLineNumbers
import { Button } from "~/components/ui/button"
```

```tsx showLineNumbers
import { For } from "solid-js"
;<div class="scrollbar-none flex scroll-fade-x gap-2 overflow-x-auto overscroll-x-contain">
  {
    <For each={suggestions}>
      {(suggestion) => (
        <Button
          variant="outline"
          size="sm"
          class="shrink-0"
          onClick={() => send(suggestion)}
        >
          {suggestion}
        </Button>
      )}
    </For>
  }
</div>
```

## Scrolling

The row scrolls sideways when the suggestions do not fit. [`scroll-fade-x`](/docs/#shared-styles) fades the edge that has more to show, and `shrink-0` keeps each label on one line.

## AI SDK

The label is the message. Send it as is.

```tsx showLineNumbers
sendMessage({ text: suggestion })
```

## Migrating from AI SDK Elements

If you added Suggestion from [AI SDK Elements](https://elements.ai-sdk.dev), your project has a `components/ai-elements/suggestion.tsx` wrapper. Paste this prompt into your coding agent to rebuild it on Button. Every export keeps its name and props, so the code that uses it keeps working.

```txt title="Prompt" prompt
Migrate components/ai-elements/suggestion.tsx from AI SDK Elements to the Solid UI Button component.

Keep every export, with the same name and props, so the code that imports it keeps working. Only change how each part renders.

1. Install Button: npx solidui-cli@latest add button
2. Read https://www.solid-ui.com/docs/ai-elements/suggestion.md and build Suggestion the same way.
3. Rebuild each part:
   - Suggestions renders a div with class="flex scroll-fade-x scrollbar-none gap-2 overflow-x-auto overscroll-x-contain", instead of a ScrollArea. Change SuggestionsProps to ComponentProps<"div">.
   - Suggestion renders a Button with variant="outline", size="sm" and class="shrink-0". Keep onClick, called with the suggestion.
4. Remove the imports the file no longer uses.
5. Run the type checker and fix any errors.
```
