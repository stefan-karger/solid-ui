## Environment

| Variable | Description |
| -------- | ----------- |
| `SOLIDUI_REGISTRY_URL` | Override registry host (default `https://www.solid-ui.com`). Use when testing a fork or a pinned docs deploy. |

## init

```bash
npx solidui-cli@latest init
```

Flags:

- `-y, --yes` — use default paths and TypeScript without prompts
- `--with-color-mode` — install `@kobalte/core` and write `COLOR_MODE.md` setup snippets
- `--with-tailwind` — install `tailwindcss`, `postcss`, `autoprefixer` (dev) and create `postcss.config.cjs` if missing

Creates `ui.config.json` with `aliases.components` (default `~/components/ui`) and `aliases.utils` (default `~/lib/utils`).

## add

```bash
npx solidui-cli@latest add button mode-toggle
```

- `-o, --overwrite` — replace existing component files
- `-y, --yes` — treat as overwrite when files exist (skip confirm)
- `-a, --all` — install every UI component (large)

## add-block

```bash
npx solidui-cli@latest add-block sidebar-01
```

Installs multi-file layouts using `target` paths from the registry (e.g. SolidStart `src/routes/...`). UI `registryDependencies` are installed automatically.

## update

```bash
npx solidui-cli@latest update button
npx solidui-cli@latest update --all
```

Re-fetches components from the registry and overwrites files (same as `add` with overwrite).
