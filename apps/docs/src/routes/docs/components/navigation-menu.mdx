## Installation

### CLI

```package-exec
solidui-cli@latest add navigation-menu
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.


## Usage

```tsx showLineNumbers
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuTrigger,
} from "~/components/ui/navigation-menu";
```

```tsx showLineNumbers
<NavigationMenu>
  <NavigationMenuItem>
    <NavigationMenuTrigger>Item One</NavigationMenuTrigger>
    <NavigationMenuContent>
      <NavigationMenuLink href="/docs">Link</NavigationMenuLink>
    </NavigationMenuContent>
  </NavigationMenuItem>
</NavigationMenu>
```

## Composition

`NavigationMenu` renders its own list wrapper internally, so items are placed directly inside it.
Use the following composition to build a `NavigationMenu`:

```text
NavigationMenu
├── NavigationMenuItem
│   ├── NavigationMenuTrigger
│   └── NavigationMenuContent
│       ├── NavigationMenuLink
│       └── NavigationMenuLink
└── NavigationMenuItem
    └── NavigationMenuLink
```

## Examples

### Link Component

Use the `as` prop to compose a custom link component such as TanStack/solid-router `Link`.

```tsx showLineNumbers
import Link from "next/link";

import {
  NavigationMenuItem,
  NavigationMenuLink,
  navigationMenuTriggerStyle,
} from "@/components/ui/navigation-menu";

export function NavigationMenuDemo() {
  return (
    <NavigationMenuItem>
      <NavigationMenuLink
        as={Link}
        to="/docs"
        class={navigationMenuTriggerStyle()}
      >
        Documentation
      </NavigationMenuLink>
    </NavigationMenuItem>
  );
}
```
