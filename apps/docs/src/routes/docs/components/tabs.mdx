## Installation

### CLI

```package-exec
solidui-cli@latest add tabs
```

### Manual

Copy and paste the following code into your project.

```file="~/registry/ui/tabs.tsx" showLineNumbers

```

## Composition

Use the following composition to build `Tabs`:

```plaintext
Tabs
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```
