## Installation

### CLI

```package-exec
solidui-cli@latest add slider
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/slider.tsx" showLineNumbers

```

## Usage

```tsx showLineNumbers
import { Slider } from "~/components/ui/slider";
```

```tsx showLineNumbers
<Slider defaultValue={[33]} maxValue={100} step={1} />
```
