## Installation

### CLI

```package-exec
solidui-cli@latest add toggle-group
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/toggle-group.tsx" showLineNumbers

```

## Composition

Use the following composition to build a `ToggleGroup`:

```plaintext
ToggleGroup
├── ToggleGroupItem
└── ToggleGroupItem
```
