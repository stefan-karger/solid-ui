## Installation

### CLI

```package-exec
solidui-cli@latest add skeleton
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/skeleton.tsx" showLineNumbers

```

## Usage

```tsx showLineNumbers
import { Skeleton } from "~/components/ui/skeleton";
```

```tsx showLineNumbers
<Skeleton class="h-[20px] w-[100px] rounded-full" />
```
