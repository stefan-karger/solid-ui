## Installation

### CLI

```package-exec
solidui-cli@latest add input
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/input.tsx" showLineNumbers

```

## Usage

```tsx showLineNumbers
import { Input } from "~/components/ui/input";
```

```tsx showLineNumbers
<Input />
```

Use the `aria-invalid` prop to mark the input as invalid. To style the invalid state, add the `data-invalid` attribute to the `Field` component.

## API Reference

`Input` is a styled native input element. See the [HTML input element reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) for its native props, keyboard behavior, and accessibility semantics.

| Prop           | Type     | Default |
| -------------- | -------- | ------- |
| `class`        | `string` |         |
| `defaultValue` | `string` |         |
