## Installation

### CLI

```package-exec
solidui-cli@latest add textarea
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/textarea.tsx" showLineNumbers

```

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";
```

```tsx
<Textarea />
```
