## Installation

### CLI

```package-exec
solidui-cli@latest add switch
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/switch.tsx" showLineNumbers

```

## Usage

```tsx showLineNumbers
import { Label } from "~/components/ui/label";
import { Switch } from "~/components/ui/switch";
```

```tsx showLineNumbers
<div class="flex items-center gap-3">
  <Switch id="airplane-mode" />
```

## API Reference

`Switch` wraps [`@kobalte/core/switch`](https://kobalte.dev/docs/core/components/switch), which implements the [WAI-ARIA switch role](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/switch_role), including keyboard, disabled, and form behavior. See the [Kobalte API reference](https://kobalte.dev/docs/core/components/switch#api-reference) for the full set of props, such as `checked`, `defaultChecked`, `onChange`, `disabled`, `required`, `readOnly`, `name`, and `value`.
