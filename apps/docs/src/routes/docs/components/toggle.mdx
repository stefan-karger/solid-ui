## Installation

### CLI

```package-exec
solidui-cli@latest add toggle
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/toggle.tsx" showLineNumbers

```

## API Reference

### Toggle

The `Toggle` component is a wrapper around the `button` element that adds a variety of styles and the toggling functionality.

| Prop             | Type                                                                          | Default     |
| ---------------- | ----------------------------------------------------------------------------- | ----------- |
| `variant`        | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"` | `"default"` |
| `size`           | `"default" \| "sm" \| "lg"`                                                   | `"default"` |
| `as`             | `ValidComponent`                                                              |             |
| `children`       | `Element \| (state: ToggleButtonRootState) => Element \| null \| undefined`   |             |
| `pressed`        | `boolean \| undefined`                                                        |             |
| `defaultPressed` | `boolean \| undefined`                                                        |             |
| `onChange`       | `(pressed: boolean) => void \| undefined`                                     |             |
| `onClick`        | `(e: Event) => void \| undefined`                                             |             |
| `disabled`       | `boolean \| undefined`                                                        |             |
