## Installation

### CLI

```package-exec
solidui-cli@latest add separator
```

### Manual

Install the following dependencies:

```package-install
@kobalte/core
```

Copy and paste the following code into your project.

```file="~/registry/ui/separator.tsx" showLineNumbers

```

## Usage

```tsx showLineNumbers
import { Separator } from "~/components/ui/separator";
```

```tsx showLineNumbers
<Separator />
```
