Components and examples get their icons from an icon library again, starting with Lucide's Solid 2 package, `@lucide/solid`.

**Breaking changes**

- Registry items name icons with an `IconPlaceholder` instead of inline SVG and need solidui-cli with icon library support to install.
- The component code on the docs imports its icons from `@lucide/solid`; the manual installation steps list it.

**Docs**

- The Create page has an Icon Library picker, and preset codes carry the icon library.
